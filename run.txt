Install
python3 --version
Python 3.10 or newer; no third-party dependencies.

Start
python3 document_room.py add policy.md --tag legal --tag policy
Prints metadata for the sample policy and saves the local index.

Smoke Test
python3 document_room.py search --tag legal
Returns the policy metadata in a JSON array.
python3 document_room.py archive meeting.txt
Marks a registered document archived (index only; --restore marks it active); search/export accept --archive-state all|active|archived, defaulting to all.
python3 document_room.py category policy.md --value "Legal Team"
Assigns a single category to a registered document (index only; an empty value marks it uncategorized); search/export accept --category to filter, and omitting it keeps every category.
python3 document_room.py export --release "Q4 Launch"
Checks the registered files and reports ready, changed, missing, unsafe or unreadable; complete is true only when every listed document is ready.
python3 document_room.py impact meeting.txt
Lists registered documents that reference the target, each with its minimum reference-edge distance; --transitive also includes indirect referrers.
python3 document_room.py duplicates --tag release
Groups registrations with equal stored bytes and SHA-256 into duplicate groups; --tag (repeatable) and --text filter like search and any member match returns the whole group.
python3 document_room.py compare --before old.json --after new.json
Diffs two exported manifest snapshots into added, removed, changed and unchanged documents without touching the index or files.
python3 document_room.py import --from records.json
Merges a UTF-8 JSON object of path-keyed records into the index (metadata only; files are not read), reporting added and unchanged paths; conflicting or invalid records fail the whole batch with exit 2.
python3 document_room.py dump --tag legal --text policy
Prints a bare JSON object of the filtered records and every record they reference, sorted by path; the output imports directly into an empty index, and files are neither read nor copied.
