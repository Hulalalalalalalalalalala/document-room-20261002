# Document Room

A local file metadata index. Python 3.10+ and the standard library are sufficient.

Run `python3 document_room.py add policy.md --tag legal --tag policy` from this directory to index the sample policy. Add the second sample with `python3 document_room.py add meeting.txt --tag operations`. `python3 document_room.py search --tag legal --text policy` returns matching metadata as JSON. Multiple tags are combined with AND; tags are trimmed and lowercase, and text matches the relative path without case sensitivity.

`python3 document_room.py export --release "2026 Q4" --tag legal` exports a release manifest: `{"release", "complete", "documents"}`. The release name is required, trimmed of surrounding whitespace. Documents use the same tag/AND and case-insensitive path-text filters as search, sorted by recorded relative path. Each entry keeps `path`, `name`, `bytes`, `sha256`, `tags` and adds `status`: `ready` when the live file's bytes and SHA-256 match the index, `changed` when either differs, `missing` when the file is absent, a dangling link or now a directory, `unsafe` when the recorded path resolves outside the document root (the target is not read), and `unreadable` for any other resolution or read failure. `complete` is true only when the manifest is non-empty and every document is ready; an empty manifest still returns all three top-level fields. The Python equivalent is `DocumentRoom.export_manifest`.

The default document root is `samples`; metadata is persisted in `.state/documents.json`. Override these with `--root` and `--index` before the subcommand. Re-adding a file refreshes its size, SHA-256 and tags. Search reads the stored metadata, not live file contents. Export only reads the index and the documents to check them: it never copies files, writes a manifest or updates the index. A missing index yields an empty manifest without creating one. A missing, blank or non-string release raises `ValueError`; an unparseable or structurally invalid index raises `ValueError`, and an unreadable index raises `OSError`. Files must resolve inside the document root. This version does not copy documents, extract content or watch filesystem changes. Use the Python `DocumentRoom.add`, `DocumentRoom.search` and `DocumentRoom.export_manifest` methods for the same operations. CLI errors return JSON and exit 2; a successful export exits 0 even when the release is incomplete.

Run `python3 -B -m unittest -v` for the API, path-boundary and CLI tests.
